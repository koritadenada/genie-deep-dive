Your IDE, your coding agent Genie Code is one option, not the only one. Keep VS Code or Cursor and Claude Code, Codex or Cursor Agent: Unity Gateway connects them to governed models, Genie and your skills.

Connect with the Unity Gateway CLI

Unity Gateway GA
# install once (needs Python 3.12+ and uv)
uv tool install git+https://github.com/databricks/unity-gateway
# launch your agent from the project folder; sign in on first use
ug claude        # Claude Code: models, MCP, skills
ug codex         # Codex: models, MCP, skills
ug mcp add --agents cursor   # Cursor IDE: MCP tools
ug cursor        # Cursor Agent CLI: MCP only

Manual alternative: point the agent at https://<workspace-hostname>/ai-gateway/anthropic (Claude Code), .../ai-gateway/codex/v1 (Codex) or .../ai-gateway/cursor/v1 (Cursor IDE) with a Databricks token.

What you get

  • Every request in system.ai_gateway.usage: user, model, tokens, session, agent
  • Coding Agents usage dashboard; spend limits with ug usage; admins can configure agents centrally
  • Unified trace table for gateway and agent traces Beta

Best practices for Genie Agents Nine habits from the official docs. Open any card for the details.
Scope and audience
One topic, one audience, few tables.

Each agent covers one business area for one audience, so Genie picks the right tables and joins.

Docs
  • One topic and one audience per agent
  • Five or fewer tables, few columns; 50 is the hard limit
  • Describe the purpose in the agent description
Data and metadata
Describe everything in Unity Catalog.

Genie reads Unity Catalog comments, keys and synonyms to choose the right tables, columns and joins.

Docs
  • Clear UC table and column descriptions
  • PK and FK become join relationships
  • Pre-join into views or metric views; hide confusing columns
Teach with SQL
SQL over prose, every time.

Example queries and SQL expressions show Genie the exact logic, which works better than describing it in text.

Docs
  • Example SQL titled with the typical phrasing
  • Parameters and SQL functions as trusted assets
  • SQL expressions for measures, filters, fields
  • Join relationships when keys are not enough
Prompt matching
Match values users actually type.

Maps what users type, such as "tik tok", to the value stored in the data, such as "TikTok Ads".

Docs
  • Format assistance is on by default
  • Entity matching on categorical strings: up to 120 columns, 1,024 values each
  • A row filter excludes the whole table from prompt matching
Instructions last
Text only for global rules.

Text instructions are open to interpretation: keep them for rules that SQL and metadata cannot express.

Docs
  • Text only for global rules SQL cannot express
  • Explicit clarification triggers
  • A summary section; no conflicts with the SQL
Evaluate and monitor
Measure before and after every change.

Benchmarks are test questions with known answers; rerun them to see whether a change helped or hurt.

Docs
  • Benchmarks with two to four phrasings per question
  • Rerun after every change; analyze a run with Genie Code
  • Monitor tab and feedback; feedback alone changes nothing
Govern
Answers run as the asking user.

Every answer runs with the asking user's permissions, so row filters and column masks still apply.

Docs
  • Data access is always the end user's own UC identity
  • Row filters and column masks apply per user
  • Users need SELECT and CAN VIEW or CAN RUN
  • Certify the agent; deprecate legacy assets
Compute and cost
Serverless warehouse, user identity.

Queries run on your SQL warehouse; serverless starts quickly and scales with demand.

Docs
  • Pro or serverless warehouse; serverless recommended
  • Queries over 5 minutes are cancelled: use views or trusted assets
  • User usage free through January 31, 2027; service principals billed
Lifecycle
Start small, ship as code.

Begin with a small pilot, then keep the agent in Git and deploy it like any other code.

Docs
  • Start small and plan to iterate
  • Agents as code: bundles or the management APIs
  • Clone to test changes; add agents gradually
